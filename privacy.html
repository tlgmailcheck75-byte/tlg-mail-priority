Privacy Policy

TLG Mail Priority (Android app and website) · Last updated 22 October 2026

TLG Mail Priority's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

1. Who this applies to

TLG Mail Priority is a private, non-commercial Android app and website (tlgmailcheck75-byte.github.io/tlg-mail-priority/app) for personal work use. It is not sold or advertised.

2. Google data the app accesses

With the user's permission, given on Google's own sign-in screen, the app requests one Google permission:

  • https://www.googleapis.com/auth/gmail.readonly: read-only access to Gmail messages.
  • https://www.googleapis.com/auth/drive.appdata: access only to the app's own hidden folder in the user's Google Drive. The app cannot see any other Drive files.

The app reads the sender, recipients, subject, date, message text, labels, thread information and attachment file names, types and sizes. It does not download attachment files. It cannot send, change or delete any email.

3. How the data is used

  • To sort emails into accounting categories, set a priority, write a short summary and suggest an action.
  • To plan work on the user's weekly schedule and track whether it is done.
  • To show notifications for important new emails.

All of this processing happens only on the user's own device (the phone, or the browser on the user's computer). The data is not used for advertising, is not sold, and is not used to train any AI or machine-learning model.

4. Where the data is stored

Downloaded email data and classifications are stored in the app's private storage on the phone (excluded from Android cloud backup) and, on the website, in the browser's local storage (IndexedDB) on the user's computer.

To keep the phone and the website in step, a small file with the user's own work state — task status (e.g. Done), notes, reminders, manual category/priority choices, categories, rules and VIP addresses — is saved in the hidden app folder of the user's own Google Drive. Email text is not stored there. Nobody else, including the developer, can read this folder.

There is no server. Email data is never transmitted to the developer, to any AI service or to any other third party.

5. Sharing

The app does not share Google user data with anyone. The only network connections it makes for email are to Google's own Gmail API and sign-in services. It also checks a version file to offer app updates, which sends no user data.

6. Deleting your data

  • In the app, open Settings → Disconnect (website: Settings → Sign out & remove data). This revokes access at Google and deletes downloaded email data from that device.
  • The synced work-state file can be deleted at any time in Google Drive → Settings → Manage apps → TLG Mail Priority → Options → Delete hidden app data.
  • Uninstalling the app deletes all of its data.
  • You can also remove access at any time at myaccount.google.com/permissions.

7. Security

Sign-in uses Google OAuth 2.0 through Google Play services. The user's Google password is never entered in or seen by the app.
